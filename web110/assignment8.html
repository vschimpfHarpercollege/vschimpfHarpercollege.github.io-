Database Queries

This assignment demonstrates the use of basic SQL statements practiced on W3Schools, integrated into a valid HTML webpage utilizing external CSS styling.

A. SQL SELECT Statement:

  • SELECT * FROM Customers;

B. SQL WHERE Clause (Modified for USA):

  • SELECT * FROM Customers WHERE Country = 'USA';

C. SQL COUNT() Function:

  • SELECT COUNT(CustomerID) FROM Customers;

D. SQL INSERT INTO Statement:

  • INSERT INTO Customers (CustomerName, ContactName, Address, City, PostalCode, Country) VALUES ('Cardinal', 'Tom B. Erichsen', 'Skagen 21', 'Stavanger', '4006', 'Norway');

E. SQL UPDATE Statement:

  • UPDATE Customers SET ContactName = 'Alfred Schmidt', City = 'Frankfurt' WHERE CustomerID = 1;

Reflection & Application

SQL syntax refers to the structured query language used for managing and manipulating relational databases. It provides a standardized way to perform operations such as querying data, updating records, and managing database schemas. For web browsers, SQL is particularly useful because it enables developers to interact with databases efficiently, allowing for dynamic content generation and data retrieval. This capability is essential for creating interactive web applications that require real-time data access, such as user accounts, product listings, and content management systems. By utilizing SQL syntax, developers can ensure that their applications are both robust and scalable, facilitating seamless user experiences.
